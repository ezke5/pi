This page is generated by Jekyll, a program that turns plain text files into a static website. There is no database and no server-side code.

### The three steps

1. **Read.** Jekyll walks the folder. Files that begin with a `---` block are processed; files and folders starting with `_` are inputs, not output.
2. **Render.** Markdown becomes HTML, Liquid tags (`{% raw %}{% for %}{% endraw %}`, `{% raw %}{{ title }}{% endraw %}`) are filled in, and the result is placed inside a layout.
3. **Write.** The finished files go to `_site/`. Upload that folder anywhere.

### Where things live

| Path | Role |
| --- | --- |
| `_config.yml` | Site settings, read once at start. |
| `index.html` | The single reading page. It loops over every chapter. |
| `_chapters/NN-name.md` | One chapter each. `order:` in the front matter sets the sequence. |
| `_layouts/default.html` | The page shell: top bar, contents, footer. |
| `_includes/` | Reusable fragments (`head.html`, `toc.html`). |
| `assets/css/main.css` | All styling, with three themes as variables. |
| `assets/js/reader.js` | Optional comfort: progress line, keys, theme, resume. |

### Add a chapter

Create `_chapters/11-my-topic.md`:

```text
---
order: 11
title: My topic
summary: One sentence that says what the reader will learn.
---
Write in ordinary Markdown. Use ### for sub-headings.
```

Save, and the contents list, the previous/next links, and the chapter count update themselves.

### Notes and warnings

A quoted paragraph becomes a note block. Add a label on the next line:

```text
> This is a side remark.
{: .note}
```

Use `.warn` for cautions.

### Reading comfort

Text is capped at about 65 characters per line. Use `[` and `]` to move between chapters, `t` to change theme, and the `A-` / `A+` buttons to resize text. All of it is optional; with JavaScript turned off the book still reads and the contents still link.
